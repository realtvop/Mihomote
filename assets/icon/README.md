# Mihomote 图标

用一条圆润的连接线组成字母 **M**，两端的圆点代表远程连接的节点。配色沿用应用的默认种子色 `#4F5BD5`，搭配纯白图形，不使用文字、渐变或阴影。

## 文件

| 文件 | 用途 |
|---|---|
| `mihomote.svg` | 1024 × 1024 可编辑矢量源文件；圆角外部透明 |
| `mihomote.png` | 1024 × 1024 PNG |
| `mihomote-512.png` | 512 × 512 PNG |
| `mihomote-256.png` | 256 × 256 PNG |
| `mihomote-square.png` | 1024 × 1024 不透明正方形，用于后续由系统裁切形状的平台图标 |

SVG 的图形已转为填充路径，不依赖字体、外链、滤镜或描边。所有 PNG 都从同一个 SVG 导出；正方形版本只移除背景圆角，主体图形保持一致。

## 重新导出

需要本机安装 **ImageMagick 7**，应用本身不增加依赖。在项目根目录运行：

```bash
bash assets/icon/export.sh
```

脚本先以 4 倍分辨率渲染 SVG，再缩小为各尺寸的 8-bit sRGB PNG。

本目录为图标设计资产；各平台启动图标接入与启动屏仍待完成。
